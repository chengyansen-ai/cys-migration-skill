## 🎯 解决什么痛点（放大版）

本技能服务于一条完整的 **AI 内容生产流水线**——任何一个环节翻车，整条链报废：

```
GPT Image 2 / ComfyUI 生成全身参考图  ──(本技能产出提示词)──▶  动作迁移 / 姿势迁移
        │                                                              │
        ▼                                                              ▼
   图生视频  ──────────────────────────────────────────────▶  抖音 / TikTok 发布
```

| # | 真实痛点 | 不解决的后果 | 本技能的解法 |
|---|---|---|---|
| 1 | **头大身小**（比例 1:5，目标 1:7~1:7.5） | 动作迁移直接判失败、人物替换人物畸变，成片像 Q 版娃娃 | 头身比修正技法：面部描述砍 66% + 腿脚描述增 800% + LoRA 权重补偿（cys001≤0.6）+ 135mm 长焦/膝高机位，V1→V5 实测把 1:5.5 拉回 1:7.5 |
| 2 | **鞋履被裁切** | 骨架/人物迁移吃不到脚，识别失败，**整张源图废弃重拍** | 硬约束清单：鞋履完整入镜、占比 ≥ 画面 6%、画面最底部；负向词 `cropped feet, shoes missing` 双保险 |
| 3 | **塑料感 / 一键 AI 脸** | 图生视频被识破"一眼假"，抖音**不推流**、观众秒划走 | 真实感内核（段2/3/4）：皮下血色、绒毛、水光肌、凝脂质感；负向词 `(plastic skin:1.2), oversmooth, doll face` |
| 4 | **透视畸变** | 广角把腿拉成筷子或反向压缩，比例崩坏 | 段9"全身等比无畸变无透视压缩" + 50mm 而非广角 + 工作流 135mm 长焦呼应 |
| 5 | **头占比偏高** | 平视/俯拍压不下头部，怎么调都 1:6 | 低角度仰拍 / 膝高机位（国外 Krea2 实例验证）+ 段9 强制"头≤25%" |
| 6 | **动作过多** | 图生视频人物漂移、穿模 | 迁移用 T-pose 范式：四肢自然垂直、无多余动作 |
| 7 | **背景空洞** | 抖音不出彩、完播率低 | 段8"绚丽+画框感+微粒/光束"、主色三件套（来自 3424 条爆款样本反推） |
| 8 | **角色 LoRA 放大头部** | cys001/cheng002 叠加后比例回退 1:5 | 提示词段3/段7/段9 强化下半身兜底 + 权重 cys001≤0.6、关闭 Anything_to_Real_Characters |

> 💡 这 8 条不是理论清单，是主人 **V1→V5 真实调参记录**里反复踩过的坑。本技能把它们固化成"填模板即规避"的硬约束。

## 🧩 中文 9 段式模板

顺序固定，前 4 段「面容 / 妆容 / 身材 / 装饰」是**真实感内核**（跨图高度复用），后 5 段为变量段：

```
人物：[人设]，[景别]，[场景]，年龄约20岁左右的青春年华，[站姿类型]，展现完美身材比例
面容：[真实感内核 · 东方辨识度精致五官 / 水光肌 / 圆眼有神 / 瓜子脸]
妆容：[真实感内核 · 眼妆神采 / 裸粉唇釉 / 无瑕水光底妆]
身材：[真实感内核 · 匀称挺拔 / 曲线自然 / 白皙透粉凝脂水光肌]
装饰：[发色 / 珠宝配饰 / 美甲，可按需改]
动作：[迁移范式：垂直站立 T-pose；或自由范式：重氛围]
服装：[视觉重心在下半身，写明鞋履四要素：跟高+鞋头+材质+细节+「清晰完整展示在画面最底部」]
环境：[具体场景 + 前景画框 + 中景 + 远景 + 光效 + 主色调]
摄像：[迁移范式：全身等比无畸变 / 头≤25% / 腿≥65% / 鞋履清晰；或自由华丽范式]
```

> 原则：**提示词本体用中文**（中文描述 + 英文摄影参数），复杂详细优先，长度无限制。动作迁移走路线 A 并强制套用下方「动作迁移硬性约束」。

## 🎬 动作迁移硬性约束

生成「动作迁移源图」时**逐条核对**，缺一条就补：

- [ ] 全身垂直站立 / 标准采集站姿（T-pose）
- [ ] 双脚平行或并拢，双手自然下垂贴身体两侧，手指放松
- [ ] 头部正直、面部正对镜头、下巴微收；双肩下沉水平；脊柱笔直；双膝伸直；脚踝并拢
- [ ] 鞋履完整入镜、清晰可见，占比 ≥ 画面高度 6%
- [ ] 头部面部占比 ≤ 画面总高 25%；腰部到脚底腿部区域 ≥ 人物高 65%
- [ ] 全身等比无畸变、无透视压缩；无 AI 痕迹
- [ ] 8K 超高清、RAW 格式、焦点从头到脚全部清晰锐利（尤其开衩腿部与鞋履细节）
- [ ] 构图完美居中，人物占画面约 80% 高度

## 📈 头身比修正实战技法

本技能最值钱的实战经验，来自主人 **V1→V5 真实迭代**（把 1:5.5 拉到 1:7~1:7.5）。提示词只是其中一环，**提示词 + LoRA 权重 + 机位**三件套联动才生效：

1. **Token 权重反转（最关键）**：面部/头部描述砍约 66%（用精简版替代完整版）；腿/脚/下半身描述增约 800%（段7 写"视觉重心在下半身占 4/5"，段9 强"腿≥65%、鞋履≥6%"）。原理：模型对 token 长度敏感，描述重心 = 画面重心。
2. **LoRA 权重补偿**：`cys001` 权重 ≤ 0.6（其训练数据多为特写，天然放大头部）；关闭 `Anything_to_Real_Characters`。
3. **机位配合**：135mm 长焦（压缩透视拉长身形）+ 膝盖高度低机位（压低头部占比）。
4. **硬性站立约束**：标准采集站姿 + 头≤25% + 腿≥65% + 鞋履入镜，杜绝坐姿/俯拍误读。

> 稳定到 1:7.5 后，即可用 9 段式模板**批量跑全部 600 条**（战甲1-6 + 迁移），规模化生产。
