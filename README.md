# cys 人像提示词库（cys-portrait-prompts）

中文 9 段式人像提示词创作体系：模板 + 风格预设 + 批量生成器，覆盖全身照与上半身中景照。

---

## 一、情况说明

写人像提示词时，经常会遇到几类反复出现的问题：

- 提示词散乱，每次从零写，风格不统一、协调度低；
- 全身像容易头大身小、鞋履被裁切、背景空洞；
- 批量生成时服装 / 饰品 / 鞋履 / 背景各说各话，容易「换皮」；
- 不同模型（ComfyUI / Krea2 / GPT Image 2 等）对提示词的吃法不同，模板难以复用。

本仓库把经过大量出图验证的写法，沉淀成一套结构化、可直接出图的 9 段式人像提示词体系，并配套风格词库与批量生成器，用来稳定地产出高质量人像提示词。

## 二、介绍

这是一套面向人像 AI 生成的**中文 9 段式提示词创作体系**。它把一张人像提示词拆成 9 个固定段落——人物、面容、妆容、身材、装饰、动作、服装、环境、摄像——前 4 段是高度复用的「真实感内核」，后 5 段按每张图的需求自由填充。

仓库包含：

- `SKILL.md`：技能本体，定义 9 段式模板、双版本构图、风格调用方式与工作流；
- `references/`：风格预设、写实语料库、热点穿搭库、协调生成方法论等参考资料；
- `scripts/`：千条级批量提示词生成器与自测脚本；
- `assets/`：9 段式结构图与仓库头图。

本仓库不绑定任何硬性约束与自动校验，把创作空间交还给使用者。

## 三、作用

- 把人像提示词从「零散描述」整理成「结构化模板」，降低每次从零写的成本；
- 提供可直接复制粘贴、喂给模型出图的完整提示词；
- 提供国风 10 类 + 现代 / 海外 20+ 种风格预设，一键套用；
- 支持一次生成上百上千条、且四类（服装 / 饰品 / 鞋履 / 背景）按风格协调匹配的批量生产；
- 同时覆盖全身照与上半身中景照两种常用构图。

## 四、好处

- **结构清晰**：9 段顺序固定，新人也能照模板填出专业级提示词；
- **复用度高**：前 4 段真实感内核跨图复用，只改后 5 段变量段即可；
- **风格丰富**：内置国风、仙侠、赛博、复古港风、法式等多种风格签名；
- **量产稳定**：生成器按大类协调词库拼接，减少「换皮」与内部冲突；
- **无约束包袱**：没有强制 CHECK LIST、没有自动合规拦截，创作自由；
- **跨平台**：模板同时适配 ComfyUI / Krea2 / GPT Image 2 等模型链路。

## 五、使用规范（建议，非强制）

## 六、格式（9 段式模板）

顺序固定：**人物 → 面容 → 妆容 → 身材 → 装饰 → 动作 → 服装 → 环境 → 摄像**

```
人物：[人设]，[景别]，[场景]，年龄约20岁，[站姿类型]
面容：[真实感内核：东方精致五官 / 水光肌 / 圆眼有神 / 瓜子脸]
妆容：[真实感内核：清透底妆 / 淡雅眼妆 / 裸粉唇釉]
身材：[真实感内核：匀称挺拔 / 曲线自然 / 白皙透粉凝脂肌]
装饰：[发色 / 珠宝配饰 / 美甲，可按需改]
动作：[垂直站姿范式 / 自由范式]
服装：[视觉重心在下半身，鞋履四要素：颜色+跟高+材质+鞋头+细节]
环境：[具体场景 + 前景画框 + 中景 + 远景 + 光效 + 主色调]
摄像：[光照名 + 光位质感 + 虚化 + 8K + 主色 + 氛围]
```

> 提示词本体用中文，复杂详细优先，长度无限制。前 4 段可整段复用，后 5 段按图定制。

双版本构图对照、各段写法细则见 `SKILL.md`。

## 七、使用方法

**1. 取仓库**

```
git clone https://github.com/chengyansen-ai/cys-portrait-prompts.git
```

**2. 作为技能加载（任选其一）**

- WorkBuddy / Claude / Codex 等：把本仓库目录放入对应 `skills/` 目录即可调用；
- 手动：直接打开 `SKILL.md` 或 `README.md`，复制模板与提示词使用。

**3. 跑批量生成器（可选）**

```
cd scripts
python gen_v3.py 20            # 全身照批量生成 20 条
python gen_v4_halfbody.py 20   # 上半身中景照 20 条
python selftest.py             # 自测：生成 + 唯一性检查
```

生成器仅用 Python 标准库，无需安装第三方依赖。
