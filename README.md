## 🎯 解决什么痛点

无论你用哪个平台出人像图，以下 8 个坑都会被本技能的硬约束直接规避：

| # | 真实痛点 | 不解决的后果 | 本技能的解法 |
|---|---|---|---|
| 1 | **头大身小**（比例 1:5，目标 1:7~1:7.5） | 动作迁移判失败、人物替换畸变，成片像 Q 版娃娃 | 头身比修正技法：Token 权重反转（面部描述精简、下半身描述强化）+ LoRA 权重补偿 + 135mm 长焦 |
| 2 | **鞋履被裁切** | 骨架/人物迁移吃不到脚，识别失败，整图废弃重拍 | 硬约束：鞋履完整入镜、占比 ≥ 6%、画面最底部；负向词双保险 |
| 3 | **塑料感 / 一键 AI 脸** | 图生视频被识破"一眼假"，平台不推流 | 真实感内核（皮下血色、绒毛、水光肌）+ 负向词 `(plastic skin:1.2)` |
| 4 | **透视畸变** | 广角把腿拉成筷子或反向压缩 | "全身等比无畸变" + 50mm + 长焦呼应 |
| 5 | **头占比偏高** | 平视/俯拍压不下头部 | 低角度仰拍 / 膝高机位 + 强制"头≤25%" |
| 6 | **动作过多** | 图生视频人物漂移、穿模 | 迁移用 T-pose 范式：四肢自然垂直、无多余动作 |
| 7 | **背景空洞** | 平台不出彩、完播率低 | "绚丽+画框感+微粒/光束"、主色三件套（来自 3424 条爆款反推） |
| 8 | **角色 LoRA 放大头部** | 叠加时比例失衡 | 提示词强化下半身兜底 + 权重补偿 |

## 🚀 安装与使用（多平台）

本技能是 **Anthropic Agent Skills 开放格式**（`SKILL.md` + `references/`），可被任意兼容客户端加载。以下列出主流平台的正确接入方式。

### 方式一：扣子（Coze）编程【已核实】

> 扣子创建技能支持三种方式：输入需求创建 / GitHub 链接创建 / **上传打包好的 Skill**。入口在「扣子编程」开发平台（注意 `coze.cn/skills` 是技能**商店浏览页**，无上传按钮）。

1. 进入 **扣子开发平台**（coze.cn → 右侧「扣子编程」）。
2. 左侧「技能」→ 右上角「创建技能」→ 选 **「上传打包好的 Skill」**。
3. 上传本仓库打包的 `.zip`（含 `SKILL.md`），系统自动解析。
4. 部署后，在对话框输入 `@` 即可调用。
5. 上架公开商店：需准备 3 个使用案例（对话链接 + 配图）提交审核。

### 方式二：Dify

Dify 通过「自定义工具 / 插件」或「提示词模板」接入本技能的方法论：

- **提示词模板法（最快）**：在 Dify 应用编排的提示词里，将本技能 9 段式作为模板，用 `{{人物}} {{场景}} {{风格}}` 等变量占位，运行时动态填充。
- **自定义工具法**：把提示词生成逻辑封装为 API（按 OpenAPI 规范），在 Dify「工具」→「自定义」中接入。
- **插件法**：按 Dify Plugin 规范打包发布为插件，供团队复用。

### 方式三：Claude Code / Claude.ai（官方 Agent Skills）

放入 skills 目录，Claude 自动按 `SKILL.md` 的 frontmatter 注册：

- 用户级：`~/.claude/skills/cys-migration-skill/`
- 项目级：`<项目>/.claude/skills/cys-migration-skill/`

### 方式四：Codex CLI（OpenAI）【Agent Skills 系统】

Codex 内置 Agent Skills 任务扩展机制（与 Claude Code 同款标准化技能包），放入技能目录即自动加载：

- 用户级：`~/.codex/skills/cys-migration-skill/`

### 方式五：其他兼容 Agent Skills 的客户端

- **Cursor / Windsurf / Cline / Aider / Continue** 等支持 `SKILL.md` 的客户端，把仓库放入对应 skills 目录即可。
- **爱马仕等国产智能体平台**：只要支持 `SKILL.md` 导入或提示词模板，均可按 Agent Skills 格式接入。
- **通用规则**：任何兼容 **Anthropic Agent Skills 格式**（`SKILL.md` + `references/`）的客户端都能加载本技能。

## 🧩 中文 9 段式模板

顺序固定，前 4 段「面容 / 妆容 / 身材 / 装饰」是**真实感内核**（跨图高度复用），后 5 段为变量段：

```
人物：[人设]，[景别]，[场景]，年龄约20岁左右的青春年华，[站姿类型]，展现完美身材比例
面容：[真实感内核 · 东方辨识度精致五官 / 水光肌 / 圆眼有神 / 瓜子脸]
妆容：[真实感内核 · 眼妆神采 / 裸粉唇釉 / 无瑕水光底妆]
身材：[真实感内核 · 匀称挺拔 / 曲线自然 / 白皙透粉凝脂水光肌]
装饰：[发色 / 珠宝配饰 / 美甲，可按需改]
动作：[迁移范式：垂直站立 T-pose；或自由范式：重氛围]
服装：[视觉重心在下半身，写明鞋履四要素：跟高+鞋头+材质+细节+「清晰完整展示在画面最底部」]
环境：[具体场景 + 前景画框 + 中景 + 远景 + 光效 + 主色调]
摄像：[迁移范式：全身等比无畸变 / 头≤25% / 腿≥65% / 鞋履清晰；或自由华丽范式]
```

> 原则：**提示词本体用中文**（中文描述 + 英文摄影参数），复杂详细优先，长度无限制。动作迁移场景套用下方「动作迁移硬性约束」。

## 🎬 动作迁移硬性约束

生成「动作迁移源图」时**逐条核对**，缺一条就补：

- [ ] 全身垂直站立 / 标准采集站姿（T-pose）
- [ ] 双脚平行或并拢，双手自然下垂贴身体两侧，手指放松
- [ ] 头部正直、面部正对镜头、下巴微收；双肩下沉水平；脊柱笔直；双膝伸直；脚踝并拢
- [ ] 鞋履完整入镜、清晰可见，占比 ≥ 画面高度 6%
- [ ] 头部面部占比 ≤ 画面总高 25%；腰部到脚底腿部区域 ≥ 人物高 65%
- [ ] 全身等比无畸变、无透视压缩；无 AI 痕迹
- [ ] 8K 超高清、RAW 格式、焦点从头到脚全部清晰锐利（尤其开衩腿部与鞋履细节）
- [ ] 构图完美居中，人物占画面约 80% 高度

## 📈 头身比修正实战技法

本技能最值钱的实战经验，来自真实**出图验证**，可将头大身小从 1:5.5 修正到 1:7~1:7.5。提示词只是其中一环，**提示词 + LoRA 权重 + 机位**三件套联动才生效：

1. **Token 权重反转（最关键）**：面部/头部描述大幅精简（用精简版替代完整版）；腿/脚/下半身描述显著强化（段7 写"视觉重心在下半身占 4/5"，段9 强"腿≥65%、鞋履≥6%"）。原理：模型对 token 长度敏感，描述重心 = 画面重心。
2. **LoRA 权重补偿**：角色 LoRA 权重 ≤ 0.6（其训练数据多为特写，天然放大头部）；叠加时关闭互相冲突的放大类 LoRA。
3. **机位配合**：135mm 长焦（压缩透视拉长身形）+ 膝盖高度低机位（压低头部占比）。
4. **硬性站立约束**：标准采集站姿 + 头≤25% + 腿≥65% + 鞋履入镜，杜绝坐姿/俯拍误读。
