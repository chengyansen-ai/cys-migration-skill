# 协调生成方法论（v3）

> 配套生成器：`scripts/gen_v3.py`
> 产出：按 15 大类协调的全身人像提示词（默认 1000 条），拆分存于 `output/`

本文档把 v3 生成器的核心设计讲透，方便后续改词库、调风格、复跑时少踩坑。

---

## 0. 一句话目标

一次出 1000 条提示词，满足四条标准：

1. **四类协调**：服装 / 饰品 / 靴鞋 / 背景 按 15 大风格类**成套搭配**，不各说各话。
2. **背景唯一**：1000 条背景（场景 × 光影）互不重复，且全程不卡死。
3. **搭配自洽**：领型 × 袖型 不出现逻辑矛盾（如高领配细吊带）。
4. **风格统一**：每条贴合所属风格类的审美基调。

---

## 1. 四类协调的数据骨架

所有「协调」的本质是：**把搭配关系固化为「大类 → 专属词库」，生成时只在该类词库内取，绝不跨类随机。**

### 1.1 服装款式 `CATEGORIES[cat]["g"]`
每类 14 款专属服装。例：
- 国风新中式：`改良旗袍 / 马面裙 / 新中式立领衬衫 / 宋锦提花外套 / 云肩上衣 / 斜襟盘扣袄 / …`
- 暗黑哥特：`漆皮束腰上衣 / 蕾丝长裙 / 暗黑斗篷 / 铆钉皮裙 / 哥特束身衣 / …`
- 多巴胺撞色：`撞色块连衣裙 / 荧光色套装 / 彩虹条纹上衣 / …`

### 1.2 推荐靴鞋 `CATEGORIES[cat]["shoes"]`（每类 5 款专属）
- 国风新中式：`绣花鞋 / 玛丽珍 / 平底浅口鞋 / 低跟单鞋 / 玛丽珍凉鞋`
- 暗黑哥特：`马丁靴 / 及踝靴 / 厚底靴 / 铆钉靴 / 系带靴`
- 运动机能：`运动鞋 / 训练鞋 / 老爹鞋 / 跑步鞋 / 网球鞋`

### 1.3 饰品 `CAT_ACCESSORIES[cat]`（每类 8-12 款专属）
v2 及之前饰品从全库随机取，常出现「暗黑哥特配珍珠发带」之类违和。改为每类专属：
- 国风新中式：`发簪 / 绒花发簪 / 点翠发簪 / 和田玉坠 / 银项圈 / 青金石项链 / 玉石耳环 / 翡翠戒 / 刺绣肩披 / 流苏额饰 / 银錾花臂钏 / 红珊瑚手串`
- 暗黑哥特：`十字架项链 / 颈链 / 银项圈 / 宝石肩链 / 身体链 / 皮革手环 / 金属颈链 / 耳骨夹`
- 芭蕾风：`发带 / 花冠 / 珍珠耳环 / 颈链 / 刺绣肩披 / 流苏额饰`

### 1.4 背景主题 `CAT_BG[cat]` + `SAFE_UNIVERSAL`（每类 11+ 个专属场景）
- 国风新中式：`中式牡丹园 / 寺庙山门 / 宫殿大厅 / 民居天井 / 钟楼内部 / …`
- 暗黑哥特：`哥特教堂中殿 / 修道院回廊 / 城堡石厅 / 废弃纺织厂 / 货运仓库 / …`
- Y2K辣妹：`霓虹赛博朋克街景 / 霓虹雨夜街 / 太空投影 / AI增强背景 / 镜面水景台 / …`

`SAFE_UNIVERSAL`（30 个，并入每一类）：
`阁楼落地窗 / 屋顶花园 / 画廊白立方 / 玻璃花房 / 植物温室 / 温室顶棚 / 樱花小径 / 秘密花园 / 英式玫瑰园 / 油画长廊 / 文艺复兴古典厅 / 丁达尔光森林 / 松林小径 / 枫树隧道 / 自然肌理墙面 / 黄金时刻棚拍 / 胶片颗粒质感 / 摩天楼停机坪 / 高层写字楼天台 / 教堂屋顶 / 水塔平台 / 现代艺术馆 / 雕塑中庭 / 植物环绕布景 / 油画质感布景 / 苔藓盆景园 / 法式园林 / 冰川融溪 / 雪山垭口 / 松林山坡`

> 协调度判定：生成后扫描 `饰品∈CAT_ACCESSORIES[cat]`、`靴鞋∈CATEGORIES[cat]["shoes"]`、`背景场景∈CAT_BG[cat]`，三项应接近/等于 100%。

## 2. 背景唯一性（预生成组合池 + 弹出，杜绝死循环）

### 2.1 组合规模计算
- `ALL_SCENES` = 163 个场景（CAT_BG 去重 75 + EXTRA_SCENES 88）
- `LIGHTING` = 12 种光影
- `TOTAL_COMBOS` = 163 × 12 = **1956 ≥ 1000** ✅ 足够不重复

### 2.2 实现（关键：用 pop，不用 while True）
```python
pool_by_scene = {sc: shuffle(list(LIGHTING)) for sc in ALL_SCENES}  # 每场景一个被打乱的12光影栈

def pick_background(cat):
    # 优先类内场景
    for sc in random.sample(CAT_BG[cat], len(CAT_BG[cat])):
        if pool_by_scene.get(sc):          # 该场景还有剩余光影
            return f"{sc}（{pool_by_scene[sc].pop()}）"
    # 兜底：任意仍有剩余光影的场景
    for sc in all_scenes_shuf:
        if pool_by_scene.get(sc):
            return f"{sc}（{pool_by_scene[sc].pop()}）"
    raise RuntimeError("背景组合已耗尽")     # 仅池真耗尽才报错，绝不卡死
```

> **踩坑记录**：v2 用 `while True` 找空闲组合，当 (场景×光影) 组合用尽后永远找不到空位 → 在 ~950/1000 处死循环卡死。改为「预生成组合池 + `pop()`」后，既保证唯一又保证必定终止。

### 2.3 兜底场景 `EXTRA_SCENES`（88 个）
中性、无活物、非民族建筑结构，补足组合数：
`高层写字楼天台 / 酒店露台 / 教堂屋顶 / 摩天楼停机坪 / 晨雾竹林 / 松林小径 / 红杉密林 / 热带白沙滩 / 黑色火山沙滩 / 玻璃海 / 珊瑚礁岸 / 瀑布深潭 / 温泉池畔 / 雪山垭口 / 花岗岩山脊 / 撒哈拉沙丘 / 风蚀雅丹 / 埃及文物厅 / 雕塑中庭 / 科技馆光影厅 / 英式玫瑰园 / 地下酒窖 / 天文台圆顶 / …`

## 3. 搭配逻辑自检（领型 × 袖型）

```python
HIGH = {"高领","半高领","立领","中式立领"}
LONG = {"长袖","七分袖","灯笼袖","泡泡袖","羊腿袖","荷叶边袖","喇叭袖","落肩袖","方袖"}

def conflict_check(nk, sleeve):
    if nk in HIGH and sleeve == "细吊带":        return "细吊带+高领矛盾"
    if nk == "深V" and sleeve in LONG:            return "深V+长袖矛盾"
    if nk in ("露肩","单肩") and sleeve in LONG:  return "露肩/单肩+长袖矛盾"
    return None
```
生成主循环遇到冲突即 `continue` 重试（最多 500 次），保证输出搭配自洽。

## 6. 复跑 / 改词库指引
- **换随机结果**：改 `random.seed(20260707)`。
- **加新风格类**：在 `CATEGORIES` / `CAT_ACCESSORIES` / `CAT_BG` 三处同步加同类条目（缺一不可，否则该类协调度掉）。
- **扩背景不重复上限**：往 `EXTRA_SCENES` 加中性干净场景，或直接扩 `CAT_BG` 每类场景数；组合规模 = 场景数 × 12。
- 跑完看末尾 `OK/WARN` 即可判断是否需要返工。
