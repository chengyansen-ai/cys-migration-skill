# 协调生成 + 抖音流量校验 + 冲突检测（v3 方法论）

> 产出：1000 条全身·ComfyUI 运用提示词（按 15 大类协调）。

本文档把 v3 生成器的核心设计讲透，方便后续改词库、调风格、复跑时少踩坑。

---

## 0. 一句话目标

一次出 1000 条提示词，满足四条硬标准：
1. **四类协调**：服装 / 饰品 / 靴鞋 / 背景 必须按 15 大风格类**成套搭配**，不能各说各话。
2. **背景唯一**：1000 条背景（场景×光影）互不重复，且全程不卡死。
3. **零内部冲突**：领型 × 袖型 不能出现逻辑矛盾。
4. **抖音合规**：无平台违规词，且整体审美对应当下爆款流量。

---

## 1. 四类协调的数据骨架

所有"协调"的本质是：**把搭配关系固化为"大类 → 专属词库"，生成时只在该类词库内取，绝不跨类随机。**

### 1.1 服装款式 `CATEGORIES[cat]["g"]`
每类 14 款专属服装。例：
- 国风新中式：`改良旗袍 / 马面裙 / 新中式立领衬衫 / 宋锦提花外套 / 云肩上衣 / 斜襟盘扣袄 / …`
- 暗黑哥特：`漆皮束腰上衣 / 蕾丝长裙 / 暗黑斗篷 / 铆钉皮裙 / 哥特束身衣 / …`
- 多巴胺撞色：`撞色块连衣裙 / 荧光色套装 / 彩虹条纹上衣 / …`

### 1.2 推荐靴鞋 `CATEGORIES[cat]["shoes"]`
每类 5 款专属鞋靴。例：
- 国风新中式：`绣花鞋 / 玛丽珍 / 平底浅口鞋 / 低跟单鞋 / 玛丽珍凉鞋`
- 暗黑哥特：`马丁靴 / 及踝靴 / 厚底靴 / 铆钉靴 / 系带靴`
- 运动机能：`运动鞋 / 训练鞋 / 老爹鞋 / 跑步鞋 / 网球鞋`

### 1.3 饰品 `CAT_ACCESSORIES[cat]`
每类 8-12 款专属饰品：
- 国风新中式：`发簪 / 绒花发簪 / 点翠发簪 / 和田玉坠 / 银项圈 / 青金石项链 / 玉石耳环 / 翡翠戒 / 刺绣肩披 / 流苏额饰 / 银錾花臂钏 / 红珊瑚手串`
- 暗黑哥特：`十字架项链 / 颈链 / 银项圈 / 宝石肩链 / 身体链 / 皮革手环 / 金属颈链 / 耳骨夹`
- 民族融合：`haath phool / maang tikka / 绿松石项圈 / 宝石额链 / 臂钏 / 流苏耳环 / 银项圈 / 腰链上延`

### 1.4 背景主题 `CAT_BG[cat]` + `SAFE_UNIVERSAL`
每类 11+ 个专属场景主题，并并入 30 个通用干净背景拉满类内协调：
- 国风新中式：`中式牡丹园 / 寺庙山门 / 宫殿大厅 / 民居天井 / 钟楼内部 / …`
- 暗黑哥特：`哥特教堂中殿 / 修道院回廊 / 城堡石厅 / 废弃纺织厂 / 货运仓库 / …`
- Y2K：`霓虹赛博朋克街景 / 霓虹雨夜街 / 太空投影 / AI增强背景 / 镜面水景台 / …`

`SAFE_UNIVERSAL`（30 个，并入每一类）：
`阁楼落地窗 / 屋顶花园 / 画廊白立方 / 玻璃花房 / 植物温室 / 温室顶棚 / 樱花小径 / 秘密花园 / 英式玫瑰园 / 油画长廊 / 文艺复兴古典厅 / 丁达尔光森林 / 松林小径 / 枫树隧道 / 自然肌理墙面 / 黄金时刻棚拍 / 胶片颗粒质感 / 摩天楼停机坪 / 高层写字楼天台 / 教堂屋顶 / 水塔平台 / 现代艺术馆 / 雕塑中庭 / 植物环绕布景 / 油画质感布景 / 苔藓盆景园 / 法式园林 / 冰川融溪 / 雪山垭口 / 松林山坡`

> 协调度判定：生成后扫描 `饰品∈CAT_ACCESSORIES[cat]`、`靴鞋∈CATEGORIES[cat]["shoes"]`、`背景场景∈CAT_BG[cat]`，三项应接近/等于 100%。实测：饰品 100%、靴鞋 100%、背景 92.2%（余 7.8% 落在 `SAFE_UNIVERSAL` 通用干净场景，属合理兜底）。

## 2. 背景唯一性（预生成组合池 + 弹出，杜绝死循环）

### 组合规模
- `ALL_SCENES` = 163 个场景
- `LIGHTING` = 12 种光影
- `TOTAL_COMBOS` = 163 × 12 = **1956 ≥ 1000** ✅ 足够不重复

### 实现
```python
pool_by_scene = {sc: shuffle(list(LIGHTING)) for sc in ALL_SCENES}

def pick_background(cat):
    for sc in random.sample(CAT_BG[cat], len(CAT_BG[cat])):
        if pool_by_scene.get(sc):
            return f"{sc}（{pool_by_scene[sc].pop()}）"
    for sc in all_scenes_shuf:
        if pool_by_scene.get(sc):
            return f"{sc}（{pool_by_scene[sc].pop()}）"
    raise RuntimeError("背景组合已耗尽")
```

> **关键改进**：v2 用 `while True` 找空闲组合 → 在 ~950/1000 处卡死。改为"预生成组合池 + `pop()`"后，既保证唯一又保证必定终止。

## 3. 内部冲突检测（领型 × 袖型）

```python
HIGH = {"高领","半高领","立领","中式立领"}
LONG = {"长袖","七分袖","灯笼袖","泡泡袖","羊腿袖","荷叶边袖","喇叭袖","落肩袖","方袖"}

def conflict_check(nk, sleeve):
    if nk in HIGH and sleeve == "细吊带":       return "细吊带+高领矛盾"
    if nk == "深V" and sleeve in LONG:          return "深V+长袖矛盾"
    if nk in ("露肩","单肩") and sleeve in LONG: return "露肩/单肩+长袖矛盾"
    return None
```
实测冲突数 = 0。

## 4. 抖音爆款流量合规校验

### 违规词用「精确短语」，绝不用单字
```python
BANNED = ["裸露","裸体","全裸","半裸","走光","透视","内裤","私处","色情","性暗示","情色","淫秽","露点"]
```
> **关键坑**：若用单字 `"裸"` 匹配，会误伤 `裸色高跟`（裸色鞋）、`裸粉唇`（裸粉唇膏）、`裸妆`（裸妆）——这些都是合法词。必须用精确短语白名单式匹配。实测命中 0。

### 爆款审美对齐
15 大类对应抖音/小红书当下流量审美（新中式、纯欲、Y2K、老钱静奢、芭蕾、暗黑哥特、废土机能、美式街头、波西米亚、职场通勤、运动机能、复古港风、多巴胺撞色、民族融合、韩系盐系）。

### 背景无活物硬约束
确保源图只吃人，不被背景生物干扰识别。

## 7. 复跑 / 改词库指引
- **换随机结果**：改随机种子。
- **加新风格类**：在 `CATEGORIES` / `CAT_ACCESSORIES` / `CAT_BG` 三处同步加同类条目（缺一不可，否则该类协调度掉）。
- **扩背景不重复上限**：往 `EXTRA_SCENES` 加中性干净场景。
- **调抖音口径**：改 `BANNED` 短语表（务必短语，勿降为单字）。
