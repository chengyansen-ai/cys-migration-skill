## 三、战甲边界（提示词（战甲1-6））

- 定位：中国风边界题材测试，写法=中文 9 段式 + 更强的「妩媚/诱惑/性感」动作与身材语言（身体前倾凸显胸部、腰肢微扭展臀线、勾魂眼神）。
- 与迁移的区别：战甲多用「自由范式」站姿（非 T-pose），重氛围与曲线；迁移用「采集范式」重骨架可识别。
- **边界建议**：保留"性感妩媚"形容词即可，避免器官级直白描写与性行为暗示；用"呼之欲出/若隐若现/凝脂水光"等隐喻维持美感与可出图性。用户本地 ComfyUI 无审核，但仍建议以"艺术人体/时尚大片" framing 保底。

## 四、合规写法（提示词（合规））

把战甲/华丽改合规的三板斧：
1. **降诱惑词**：删"勾魂摄魄/令人窒息的诱惑力/呼之欲出"，保留"精致/优雅/自信"。
2. **改站姿**：用「标准采集站姿 / 自然挺拔站姿」替代扭腰撩发。
3. **加艺术 framing**：摄像段加"专业时尚大片质感 / 艺术人体摄影 / 高级感"，用光影与构图说话而非露。
4. **服装加覆盖**：明确"内搭安全短裤/抹胸严密裹胸绝不走光"。

## 二十、波西米亚（Boho）

- **服装**：流苏针织开衫 + 印花长裙（层叠薄纱）+ 编织腰带 + 圆檐草帽；脚穿裸色绑带凉鞋或麂皮短靴
- **环境**：旷野花海、沙漠营地、木质露台、暖阳；整体色调：赤陶 + 芥末黄 + 焦糖
- **关键词**：free-spirited、layered、earthy

## 二十一、蒸汽朋克（Steampunk）

- **服装**：棕 leather 束腰马甲 + 铜扣长风衣 + 齿轮护目镜 + 机械臂饰；脚穿做旧马丁靴（系带，铜铆钉）
- **环境**：黄铜机械工厂、齿轮穹顶、蒸汽管道、暖烛光；整体色调：古铜 + 深棕 + 暗金
- **关键词**：Victorian、brass、clockwork

## 二十二、未来科幻（Sci-Fi / Blade Runner）

- **服装**：银白哑光连体服 + 发光线路纹路 + 透明材质披风；脚穿反光机能短靴或悬浮感透明鞋
- **环境**：悬浮都市、全息广告、冷蓝巨构建筑、雨夜；整体色调：冷银 + 电蓝 + 深空黑
- **关键词**：futuristic、holographic、megacity
